# ДAV7Д - דף נחיתה

אתר סטטי (HTML/CSS/JS, בלי ספריות חיצוניות). כתובת: https://oriantoledano-ship-it.github.io/dav7d/

## העלאה ידנית ל-GitHub Pages
1. יוצרים ריפו ריק בשם באנגלית קטנה (למשל `dav7d`).
2. נכנסים לתיקיית הפרויקט, `Ctrl+A`, וגוררים את **התוכן** (לא את התיקייה עצמה) ל-Upload files.
3. ודאו שקבצים נסתרים מוצגים (סייר הקבצים: תצוגה ← הצג ← פריטים מוסתרים) כדי ש-`.nojekyll` יעלה.
4. Settings ← Pages ← Branch: `main`, תיקייה `/ (root)` ← Save.

## אם משהו לא עובד
- הכתובת חייבת להסתיים ב-`/`.
- הקבצים צריכים לשבת בשורש הריפו, לא בתוך תיקייה.
- בדקו ש-Pages מופעל ושה-build הסתיים (לשונית Actions).

## מבנה
- `index.html` - הדף הראשי
- `accessibility.html`, `privacy.html`, `terms.html` - עמודים משפטיים
- `assets/` - עיצוב, סקריפטים, פונטים ותמונות (כל התמונות מהאינסטגרם של המותג)
